ElectraX3 - Hydrogen Powered Vehicles
A modern landing page developed during my 2023 Internship (2nd Year) to showcase the future of hydrogen-powered transportation.

Live Demo: https://electrax6.neocities.org/

🚀 Internship Project Overview
This project was completed in 2023 as a core deliverable during my sophomore year internship. The goal was to design and develop a functional, multi-page web presence for ElectraX3, focusing on clean UI and educational content regarding hydrogen fuel technology.

Key Features
Multi-Page Architecture: Integrated Home, About, Charging, and Shop pages.

Hydrogen Tech Showcase: Dedicated sections for fuel cell power and engine mechanics.

Social & Community Integration: Built-in links for Discord and major social platforms.

Responsive Foundations: Designed using core frontend principles to ensure cross-page consistency.

🛠️ Technologies Used
HTML5 & CSS3: For semantic structure and custom layout design.

JavaScript: To handle site interactivity and navigation.

Neocities: Used for deployment and hosting.
